# Fase 4 — Mídia Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mídia nos dois sentidos pelo iPhone: ver as imagens da conversa no terminal (D1), mandar foto ou arquivo
numa mensagem (D2), ditar (D3, já instalado: só conferir) e abrir os arquivos que o agente escreveu (D4).

**Architecture:** Quatro partes independentes, cada uma com servidor (TDD) e cliente. D1: o parser do terminal passa a
dar a cada imagem um id e guarda o base64 fora da entrada; o `TerminalStreams` põe as imagens num cache em memória com
teto e a rota `GET /api/terminal/image/:stream/:id` as serve (trava do terminal). D2: `POST /api/attachments` (trava das
mensagens) usa o mesmo `AttachmentStore` do Novo agente; `POST /api/messages` aceita `attachments`; a mensagem só sai
para a sessão depois que os arquivos estão gravados no Mac (Node: o servidor grava; Docker: o auxiliar do host grava,
como já faz no Novo agente) e leva os caminhos por `promptWithAttachments`. D4: `GET /api/agents/:id/files` lê do fim do
transcript os `file_path` de Write/Edit/MultiEdit/NotebookEdit e abre cada um pelo `FileFetcher` das entregas.

**Tech Stack:** Node 24 + TypeScript (tsx), Vitest, cliente em TypeScript puro (Vite), sem dependências novas.

### Como o anexo chega ao Mac (D2 no Docker)

O agente lê o anexo pelo caminho que vai no texto da mensagem, então o arquivo precisa existir **no Mac**, nesse
caminho. O container não grava no Mac: o único volume gravável é `/data` e as pastas das contas são montadas só leitura.

Quem já grava anexos no Mac é o auxiliar do host (`scripts/codex-bridge.ts`, LaunchAgent
`com.pnd.habblaud-codex-bridge`): no Novo agente ele recebe os arquivos em base64 (`spawnRound`), confere
(`checkFiles`), grava em `~/.habblaud/attachments/<data>-<id>/` com pasta 700 e arquivos 600 (`writeAttachments`) e usa
os caminhos (`promptWithAttachments`). A Fase 4 reaproveita exatamente esse caminho: as mesmas funções, o mesmo
auxiliar e o mesmo modelo de rodada com espera que ele já usa para arquivos e ditado (`HostWait`/`pollWithWait`). O
que entra é só mais um par de rotas locais (`POST /api/host/attachments/poll|ack`, já barradas na porta remota por
`isLocalOnlyPath`) e um laço `attachmentsRound` no mesmo processo. No modo Node o servidor grava direto, como o
`openDirect` do Novo agente.

Descartados: montar `~/.habblaud/attachments` no container (mexe no `docker:up`, em permissões e exige traduzir o
caminho do container para o do Mac); gravar pelo plugin `habblaud-mensagens` (só serviria ao Claude Code e exige
reinstalar o plugin); pendurar os arquivos em `POST /api/host/spawn/poll` (o `SpawnService` só existe com
`HABBLAUD_PTY=1` e a rota é do Novo agente, que segue com a trava `spawn`, não liberada no iPhone).

A mensagem com anexo fica `queued` (por dentro, "gravando") até os caminhos chegarem e só então vai à caixa do plugin
ou ao `codex queue`. As mensagens seguintes do mesmo agente esperam atrás dela (a ordem vale).

```ts
/** Imagens base64 de tipo conhecido entre os blocos, em ordem (até IMAGES_PER_ENTRY). */
function imageBlocks(blocks: readonly unknown[]): Array<{ mime: string; data: string }> {
  const out: Array<{ mime: string; data: string }> = [];
  for (const raw of blocks) {
    const src = rec(rec(raw)?.source);
    if (rec(raw)?.type !== 'image' || src?.type !== 'base64') continue;
    const mime = typeof src.media_type === 'string' ? src.media_type : '';
    const data = typeof src.data === 'string' ? src.data : '';
    if (!IMAGE_TYPES.test(mime) || !data || data.length > IMAGE_B64_MAX) continue;
    out.push({ mime, data });
    if (out.length >= IMAGES_PER_ENTRY) break;
  }
  return out;
}
```

```ts
/** Imagens guardadas para GET /api/terminal/image (todas as conexões juntas): teto de bytes e de itens. */
export const IMAGE_CACHE_BYTES = 48 * 1024 * 1024;
export const IMAGE_CACHE_ITEMS = 300;
/** Imagem maior que isto (decodificada) não entra: fica só o marcador "[imagem]" no texto. */
export const IMAGE_MAX_BYTES = 10 * 1024 * 1024;

/**
 * Imagens das conversas lidas pelos terminais, por conexão (`stream` = o agentId do `init`: id do agente ou
 * "session:<conta>:<sessionId>") e id da imagem. Entram quando o transcript é lido e saem pela ordem de uso: o
 * snapshot e o stream só levam a referência {id, mime}.
 */
export class TerminalImages {
  private readonly items = new Map<string, { mime: string; data: Buffer }>();
  private bytes = 0;

  constructor(
    private readonly maxBytes = IMAGE_CACHE_BYTES,
    private readonly maxItems = IMAGE_CACHE_ITEMS,
  ) {}

  get size(): number {
    return this.items.size;
  }

  put(stream: string, img: TerminalImageData): void {
    const key = `${stream}\n${img.id}`;
    if (this.touch(key) || !IMAGE_TYPES.test(img.mime)) return;
    const data = Buffer.from(img.data, 'base64');
    if (!data.length || data.length > IMAGE_MAX_BYTES) return;
    this.items.set(key, { mime: img.mime, data });
    this.bytes += data.length;
    for (const [k, v] of this.items) {
      if (this.bytes <= this.maxBytes && this.items.size <= this.maxItems) break;
      this.items.delete(k);
      this.bytes -= v.data.length;
    }
  }

  get(stream: string, id: string): { mime: string; data: Buffer } | undefined {
    return this.touch(`${stream}\n${id}`);
  }

  /** Item usado agora: vai para o fim da fila de saída. */
  private touch(key: string): { mime: string; data: Buffer } | undefined {
    const hit = this.items.get(key);
    if (hit) {
      this.items.delete(key);
      this.items.set(key, hit);
    }
    return hit;
  }
}
```

```ts
// Anexos das mensagens no Docker (Fase 4, D2): o container não grava no Mac, e o agente lê o anexo pelo caminho do Mac.
// Quem grava é o auxiliar do host (scripts/codex-bridge.ts), do mesmo jeito que os anexos do Novo agente (checkFiles +
// writeAttachments em ~/.habblaud/attachments/, pasta 700 e arquivos 600). O servidor deixa os arquivos aqui; o
// auxiliar busca em POST /api/host/attachments/poll (rodada com espera), grava e devolve os caminhos em
// POST /api/host/attachments/ack.
import { randomUUID } from 'node:crypto';
import { tr } from '../../shared/i18n';
import { HostWait, pollWithWait } from '../host-wait';
import type { Attachment } from './attachments';

export const HOST_PRESENCE_MS = 10_000;
export const WRITE_TIMEOUT_MS = 20_000;
const MAX_PENDING = 8;
const PATH_MAX = 4_096;

export interface PolledWrite {
  id: string;
  files: Array<{ name: string; type: string; data: string }>;
}

interface Pending {
  id: string;
  files: readonly Attachment[];
  sent: boolean;
  done: (r: { paths: string[] } | { error: string }) => void;
}

export class HostFileWriter {
  private readonly pending = new Map<string, Pending>();
  private readonly host: HostWait;

  constructor(private readonly opts: { now?: () => number; newId?: () => string; timeoutMs?: number } = {}) {
    this.host = new HostWait(HOST_PRESENCE_MS, opts.now ?? Date.now);
  }

  /** Pede ao auxiliar que grave os arquivos: os caminhos no Mac, na ordem, ou a rejeição com o motivo. */
  write(files: readonly Attachment[]): Promise<string[]> {
    if (!this.host.present()) return Promise.reject(new Error(tr('o auxiliar do computador (npm run codex:bridge) não está rodando')));
    if (this.pending.size >= MAX_PENDING) return Promise.reject(new Error(tr('anexos demais sendo gravados: tente de novo')));
    return new Promise((ok, fail) => {
      const p: Pending = { id: this.opts.newId?.() ?? randomUUID(), files, sent: false, done: (r) => ('paths' in r ? ok(r.paths) : fail(new Error(r.error))) };
      this.pending.set(p.id, p);
      this.host.wake();
      setTimeout(() => {
        if (this.pending.delete(p.id)) p.done({ error: tr('o computador não gravou os anexos a tempo') });
      }, this.opts.timeoutMs ?? WRITE_TIMEOUT_MS).unref?.();
    });
  }

  /** Rodada do auxiliar: marca presença e entrega os arquivos ainda não buscados (base64). */
  poll(): PolledWrite[] {
    this.host.seen();
    const out: PolledWrite[] = [];
    for (const p of this.pending.values()) {
      if (p.sent) continue;
      p.sent = true;
      out.push({ id: p.id, files: p.files.map((f) => ({ name: f.name, type: f.type, data: f.data.toString('base64') })) });
    }
    return out;
  }

  /** Rodada com espera (?wait=1): sem nada pedido, fica parada até chegar um pedido ou passar `ms`. */
  pollWait(ms: number, signal?: AbortSignal): Promise<PolledWrite[]> {
    return pollWithWait(this.host, () => this.poll(), ms, signal);
  }

  /** {results: [{id, ok, paths?, error?}]}: um caminho absoluto por arquivo, sem quebra de linha (vão no texto). */
  ack(raw: unknown): void {
    this.host.seen();
    const list = raw && typeof raw === 'object' && Array.isArray((raw as { results?: unknown }).results) ? (raw as { results: unknown[] }).results : [];
    for (const r of list) {
      const x = r && typeof r === 'object' ? (r as Record<string, unknown>) : {};
      const p = typeof x.id === 'string' ? this.pending.get(x.id) : undefined;
      if (!p || !p.sent) continue;
      this.pending.delete(p.id);
      const paths = Array.isArray(x.paths) ? x.paths : [];
      const valid =
        x.ok === true &&
        paths.length === p.files.length &&
        paths.every((s) => typeof s === 'string' && s.startsWith('/') && s.length <= PATH_MAX && !/[\r\n\0]/.test(s));
      p.done(valid ? { paths: paths as string[] } : { error: typeof x.error === 'string' && x.error ? x.error.slice(0, 200) : tr('o computador não gravou os anexos') });
    }
  }
}
```

```ts
  post: Post,

  opts: { wait?: boolean } = {},

  const polled = await post(`/api/host/attachments/poll${opts.wait ? '?wait=1' : ''}`, {});

  const list = rec(polled.json)?.writes;
```

```ts
const WRITE_TOOLS = new Set(['Write', 'Edit', 'MultiEdit', 'NotebookEdit']);

type Rec = Record<string, unknown>;
const rec = (v: unknown): Rec | undefined => (v && typeof v === 'object' && !Array.isArray(v) ? (v as Rec) : undefined);

/** Caminhos escritos ou editados nas linhas do transcript: sem repetir, do mais recente para o mais antigo. */
export function writtenFiles(lines: Iterable<string>): Array<{ path: string; at: number }> {
  const seen = new Map<string, number>();
  for (const line of lines) {
    if (!line.includes('"tool_use"')) continue;
    let d: Rec | undefined;
    try {
      d = rec(JSON.parse(line));
    } catch {
      continue;
    }
    const content = rec(d?.message)?.content;
    if (d?.type !== 'assistant' || !Array.isArray(content)) continue;
    const t = Date.parse(String(d.timestamp));
    const at = Number.isNaN(t) ? 0 : t;
    for (const b of content) {
      const r = rec(b);
      if (r?.type !== 'tool_use' || !WRITE_TOOLS.has(String(r.name))) continue;
      const input = rec(r.input);
      const p = typeof input?.file_path === 'string' ? input.file_path : typeof input?.notebook_path === 'string' ? input.notebook_path : '';
      if (!p) continue;
      seen.delete(p);
      seen.set(p, at);
    }
  }
  return [...seen].reverse().map(([path, at]) => ({ path, at }));
}

export interface AgentFilesOptions {
  transcriptPathOf: (agentId: string) => string | undefined;
  /** Pasta do projeto do agente (para mostrar o caminho relativo). */
  cwdOf: (agentId: string) => string | undefined;
}

export class AgentFiles {
  private readonly ids = new Map<string, Map<string, string>>();

  constructor(private readonly opts: AgentFilesOptions) {}

  /** Arquivos de ver que o agente escreveu, mais recente primeiro; undefined = agente sem transcript conhecido. */
  list(agentId: string): AgentFileInfo[] | undefined {
    const transcript = this.opts.transcriptPathOf(agentId);
    if (!transcript) return undefined;
    const lines: string[] = [];
    try {
      const tail = new FileTail(transcript);
      tail.seekTail(FILES_TAIL_BYTES);
      for (let i = 0; i < 64; i++) {
        const r = tail.read();
        lines.push(...r.lines);
        if (!r.more) break;
      }
    } catch {
      // Transcript ilegível agora: lista vazia.
    }
    const cwd = this.opts.cwdOf(agentId)?.replace(/\/+$/, '');
    const ids = new Map<string, string>();
    const out: AgentFileInfo[] = [];
    for (const f of writtenFiles(lines)) {
      if (out.length >= MAX_AGENT_FILES) break;
      const type = fileType(f.path);
      if (!type || pathProblem(f.path)) continue;
      const id = createHash('sha256').update(`${agentId}|${f.path}`).digest('hex').slice(0, 20);
      ids.set(id, f.path);
      const rel = cwd && f.path.startsWith(`${cwd}/`) ? f.path.slice(cwd.length + 1) : f.path;
      out.push({ id, name: f.path.split('/').pop() || f.path, path: rel, kind: type.kind, at: f.at });
    }
    this.ids.delete(agentId);
    this.ids.set(agentId, ids);
    if (this.ids.size > MAX_AGENTS) this.ids.delete(this.ids.keys().next().value as string);
    return out;
  }

  /** Caminho real de um id da última listagem do agente. */
  path(agentId: string, id: string): string | undefined {
    return this.ids.get(agentId)?.get(id);
  }
}
```

```ts
// Seção "Arquivos" da gaveta do agente (Fase 4, D4): os arquivos de ver que o agente escreveu ou editou na sessão
// (GET /api/agents/:id/files), do mais recente para o mais antigo. Carrega só quando você toca em "Ver arquivos"; um
// toque num arquivo o abre numa aba nova (GET /api/agents/:id/files/:fileId: imagem, PDF, vídeo, página em sandbox,
// texto). Mesma trava do terminal.
import { tr } from '../../../shared/i18n';
import type { AgentFileInfo, AgentInfo } from '../../../shared/types';
import { access } from '../net/access';
import type { UiContext } from './context';
import { h, setHidden, setText } from './dom';
import { relativeTime } from './format';

export function agentFilesUrl(agentId: string, fileId?: string): string {
  const base = `/api/agents/${encodeURIComponent(agentId)}/files`;
  return fileId === undefined ? base : `${base}/${encodeURIComponent(fileId)}`;
}

/** Itens válidos da resposta (o resto é ignorado). */
export function parseAgentFiles(body: unknown): AgentFileInfo[] {
  const list = (body as { files?: unknown } | null)?.files;
  if (!Array.isArray(list)) return [];
  return list.filter(
    (f): f is AgentFileInfo => !!f && typeof f.id === 'string' && typeof f.name === 'string' && typeof f.path === 'string' && typeof f.kind === 'string' && typeof f.at === 'number',
  );
}

export class AgentFilesSection {
  readonly el: HTMLElement;
  private readonly list: HTMLElement;
  private readonly note: HTMLElement;
  private readonly loadBtn: HTMLButtonElement;
  private agentId = '';
  /** Pedido em andamento: trocar de agente invalida a resposta que ainda vai chegar. */
  private req = 0;

  constructor(private readonly ctx: UiContext) {
    this.list = h('ul', { class: 'ui-files' });
    this.note = h('p', { class: 'ui-muted ui-small', hidden: true });
    this.loadBtn = h('button', { class: 'ui-btn ui-btn--sm', type: 'button', text: tr('Ver arquivos'), on: { click: () => void this.load() } });
    this.el = h(
      'section',
      { class: 'ui-sec' },
      h('div', { class: 'ui-sec__head' }, h('h3', { class: 'ui-sec__title', text: tr('Arquivos') }), this.loadBtn),
      this.list,
      this.note,
    );
  }

  /** Some sem a trava do terminal, no demo e no replay. Outro agente: a lista volta a ficar por carregar. */
  render(agent: AgentInfo | undefined): void {
    const store = this.ctx.store;
    setHidden(this.el, !agent || !access().terminal || !store.snapshot?.meta.terminal || store.mock || store.replaying);
    if (!agent || agent.id === this.agentId) return;
    this.agentId = agent.id;
    this.req++;
    this.list.replaceChildren();
    setHidden(this.note, true);
    setText(this.loadBtn, tr('Ver arquivos'));
  }

  private async load(): Promise<void> {
    const id = this.agentId;
    const req = ++this.req;
    setText(this.loadBtn, tr('Carregando…'));
    let files: AgentFileInfo[] = [];
    let error = '';
    try {
      const res = await fetch(agentFilesUrl(id), { credentials: 'same-origin', cache: 'no-store' });
      const body: unknown = await res.json().catch(() => ({}));
      if (res.ok) files = parseAgentFiles(body);
      else error = (body as { error?: string }).error ?? tr('erro {0}', [res.status]);
    } catch {
      error = tr('o Habblaud não respondeu');
    }
    if (req !== this.req) return;
    setText(this.loadBtn, tr('Atualizar'));
    const now = this.ctx.now();
    this.list.replaceChildren(
      ...files.map((f) =>
        h(
          'li',
          { class: 'ui-files__item' },
          h('a', { class: 'ui-files__link', text: f.name, attrs: { href: agentFilesUrl(id, f.id), target: '_blank', rel: 'noopener', title: f.path } }),
          h('span', { class: 'ui-files__meta', text: f.at ? `${f.path} · ${relativeTime(f.at, now)}` : f.path }),
        ),
      ),
    );
    const msg = error || (!files.length ? tr('Nenhum arquivo de ver (imagem, PDF, página, texto) escrito nesta sessão.') : '');
    setText(this.note, msg);
    setHidden(this.note, !msg);
  }
}
```
